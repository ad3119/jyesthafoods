# Jyestha Foods — static site

Plain HTML, CSS and images. No build step. Ready for GitHub Pages.

## Publish

1. Create a GitHub repository (public).
2. Upload **everything inside this folder** to the repository root: `index.html`, `styles.css`, `script.js`, `logo.png`, `favicon.svg`, `photos/`, and `.nojekyll`.
3. In the repo: **Settings → Pages → Build and deployment → Deploy from a branch**.
4. Branch: `main`, folder: `/ (root)`, then Save.

The site will be at `https://YOUR-USERNAME.github.io/YOUR-REPO/`.

Paths are relative, so it also works if the repository is named and served as a project site.
